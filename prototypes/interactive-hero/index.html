      How this demo decides
      1. An option has to work for every ask: Aanya’s food, Rohan’s “somewhere new”, Meera’s budget and Kabir’s time. It starts half an hour after Kabir is free, because Meera has the longest trip, and it needs two hours before the place closes.
      2. If more than one works, it prefers somewhere new, then the cheaper one.
      3. If nothing works, it doesn’t guess. It shows what each option would need, so the group can decide.

      It shows its working.

      The demo above runs on three plain rules. The real product is still being built, but the promise is the same: one plan, and the reasons you can check.

      1. 1 It has to work for all four.

        Every option is checked against every ask. One “no” and it’s set aside, with the reason.

        See every option, checked

      2. 2 New first, then cheaper.

        When more than one option works, somewhere new wins, then the cheaper one. If the plan holds, it says why.

      3. 3 If nothing fits, it says so.

        No forced pick. It shows who would have to give a little, and what that would open up.
