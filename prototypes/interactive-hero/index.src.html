    How this demo decides
    1. An option has to work for every ask: Aanya’s food, Rohan’s “somewhere new”, Meera’s budget and Kabir’s time. It starts half an hour after Kabir is free, because Meera has the longest trip, and it needs two hours before the place closes.
    2. If more than one works, it prefers somewhere new, then the cheaper one.
    3. If nothing works, it doesn’t guess. It shows what each option would need, so the group can decide.

    Four made-up friends, six made-up options and three fixed rules. Nothing here is a live recommendation, a real venue or a real price.
